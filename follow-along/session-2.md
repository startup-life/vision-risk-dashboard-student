# 2회차: 사건 등록과 목록, 내 컴퓨터 저장

- 시작 상태: 1회차를 끝낸 프로젝트 폴더 `C:\vision-ai\vision-risk-dashboard-student`에서 시작합니다. 1회차를 다 못 끝냈으면 README의 "회차를 다 못 끝냈을 때"대로 `milestone-1` 브랜치로 옮긴 뒤 시작합니다.
- 끝나면 되는 것: 사진 파일을 올리거나 사진 저장소의 사진을 골라 사건을 등록하면, 사건 목록과 홈의 "확인이 필요한 현장"에 "검토 대기"로 나옵니다. 기록과 사진은 이 PC의 `runtime` 폴더에 저장되어 서버를 껐다 켜도 남습니다.
- 준비물: AI 도구에서 연 프로젝트 폴더, 서버 창(서버를 켜 두는 PowerShell 창), 프로젝트 폴더 옆에 받은 사진 저장소(`C:\vision-ai\vision-risk-student-images`, 아래 "시작 전에"에서 받습니다).

## 먼저 알아 둘 말

- **사건**: 현장 사진 1~5장과 장소, 분류, 메모를 묶은 기록 하나입니다. 서버가 `R-101`, `R-102`처럼 번호를 붙입니다.
- **사진 저장소**: 강사가 공개한 연습용 현장 사진 모음입니다. 프로젝트 폴더 옆 `vision-risk-student-images` 폴더에 받아 두고 읽기만 합니다.
- **검토 대기**: 등록만 하고 아직 판단을 남기지 않은 사건의 상태입니다. 3회차에서 판단을 남기면 바뀝니다.

## 시작 전에 (프롬프트 없이 직접 합니다)

1. 보충 문서 받기: 시작 메뉴에서 PowerShell 창을 새로 열고 아래 세 줄을 한 줄씩 칩니다. 세 줄을 꼭 함께 칩니다. 2회차의 자세한 내용을 적은 문서가 `docs/guide` 폴더에 들어오고 내 코드는 바뀌지 않습니다. 탐색기에서 `docs\guide` 폴더를 열어 `session-2.md`가 보이면 됩니다. 이 문서는 회차 끝 커밋 때 함께 저장됩니다. 1회차를 못 끝내서 `milestone-1`로 옮겼으면 문서가 이미 있으니 건너뜁니다.

```powershell
cd C:\vision-ai\vision-risk-dashboard-student
git fetch origin
git checkout origin/milestone-1 -- docs/guide
```

2. 서버 켜 보기: 서버 창에서 `npm.cmd start`를 치고 Chrome에서 http://127.0.0.1:8765 를 엽니다. 서버 창이 없으면 시작 메뉴에서 PowerShell 창을 새로 열고 `cd C:\vision-ai\vision-risk-dashboard-student`를 친 뒤 그 창을 서버 창으로 씁니다. 1회차 홈과 "확인 기준 보기" 단추가 보이면 됩니다.
3. 사진 저장소 받기: 탐색기에서 `C:\vision-ai` 안에 `vision-risk-student-images` 폴더가 이미 있으면 건너뜁니다. 없으면 서버 창이 아닌 PowerShell 창에서(없으면 시작 메뉴에서 새로 엽니다) 아래 두 줄을 한 줄씩 칩니다. ZIP으로 받으면 쓰지 못하니 꼭 이 명령으로 받고, 폴더 이름은 바꾸지 않습니다.

```powershell
cd C:\vision-ai
git clone https://github.com/startup-life/vision-risk-student-images.git
```

4. 사진 수 확인: 서버 창이 아닌 PowerShell 창에서 아래 한 줄을 칩니다. `210`이 나와야 합니다. 탐색기에서 `C:\vision-ai` 안에 `vision-risk-dashboard-student`와 `vision-risk-student-images`가 나란히 보여야 합니다.

```powershell
(Get-ChildItem C:\vision-ai\vision-risk-student-images\assets\dataset\images -Filter *.png).Count
```

## 새 대화를 시작할 때

회차를 시작할 때와 새 대화를 열 때마다, 번호가 있는 프롬프트보다 먼저 아래를 한 번 보냅니다. 도구에 따라 이 파일을 저절로 읽지 않을 수 있어서입니다.

```text
AGENTS.md를 읽고 그 안내대로 보충 문서도 읽어 주세요. 읽은 파일 이름만 한 줄로 알려 주세요.
```
- 확인: AI 답에 `AGENTS.md`와 `session-1.md`가 나오고, 2회차부터는 이번 회차 문서 이름도 나옵니다.

## 진행 방법

- 프롬프트 상자 하나를 통째로 복사해 AI에게 붙여 넣습니다. 앞 번호가 끝난 뒤에 다음 번호를 보냅니다.
- 프롬프트는 짧습니다. 정확한 주소와 문구는 보충 문서에 있습니다. 궁금하면 `docs/guide` 폴더의 `session-2.md`를 직접 읽어 봐도 됩니다.
- AI가 파일을 만들거나 명령을 실행해도 되는지 물으면, 보낸 프롬프트와 관계있는 일인지 보고 승인합니다. 서버를 켜겠다고 하면 거절합니다. `Set-ExecutionPolicy`, `npm audit fix`처럼 컴퓨터 설정이나 프로그램 버전을 바꾸는 명령도 승인하지 말고 강사에게 알립니다.
- "직접 하기"는 AI에게 보내지 않고 내가 직접 합니다.
- 서버 끄기: 서버 창에서 Ctrl+C를 누릅니다. "일괄 작업을 끝내시겠습니까 (Y/N)?"가 나오면 `Y`를 칩니다.
- 단계가 끝날 때마다 서버를 껐다 켜고(Ctrl+C, 그다음 `npm.cmd start`) 브라우저를 새로고침한 뒤 확인을 봅니다.
- "확인"과 다르게 나오면 화면의 글이나 서버 창의 빨간 줄을 그대로 복사해 "이렇게 나와요. 고쳐 주세요."와 함께 AI에게 붙여 넣습니다.
- AI가 "이미 되어 있습니다"라고 답하면 그 번호의 "확인"만 해 보고 다음 번호로 넘어갑니다. 보충 문서에 미리 적힌 내용이라 앞 번호에서 먼저 만들어졌을 수 있습니다.
- 2회차는 단계가 많습니다. 답이 느려지거나 이상해지면 새 대화를 엽니다. 새 대화를 열면 위 "새 대화를 시작할 때"의 프롬프트를 먼저 보냅니다. 그다음 그 번호의 프롬프트부터 다시 보냅니다.
- 사진을 고를 때는 사진 고르는 창에서 `C:\vision-ai\vision-risk-student-images\assets\dataset\images` 폴더로 가서 PNG 파일을 고릅니다. 여러 장은 Ctrl을 누른 채 차례로 누릅니다.
- 확인에 적힌 사건 번호(`R-101`, `R-102`)는 적힌 대로 등록했을 때의 값입니다. 사건을 더 등록해 보았으면 번호가 더 커도 됩니다.
- 화면 색과 배치는 예시와 달라도 됩니다. "확인"에 적힌 글과 동작만 같으면 됩니다.


## 2-11. 화면: 사진 올려 사건 등록하기

```text
"사건 등록"을 누르면 입력한 장소, 분류, 메모와 사진을 요청 번호와 함께 서버에 보내 주세요. 보내는 동안 단추를 잠가 두 번 저장되지 않게 하고, 실패하면 이유를 위쪽 알림 줄 한 곳에만 보여 주고 입력은 그대로 둡니다.
저장되면 입력을 처음 상태(장소 "물류창고 A", 메모와 사진은 비움)로 되돌리고 사건 목록으로 가서, 화면 안에 "사건이 등록되었습니다: (사건 번호)"를 보여 주세요.
```
- 직접 하기: 등록 화면에서 PNG 한 장을 고르고 메모에 "첫 사건"이라고 적은 뒤 "사건 등록"을 누릅니다.
- 확인: 사건 목록 화면으로 바뀌며 "사건이 등록되었습니다: R-101"이 보입니다(4초 뒤 사라집니다). 표는 다음 번호에서 만들므로, 지금은 http://127.0.0.1:8765/api/records 를 열어 `R-101`이 있는지 봅니다. 등록 화면을 다시 열면 장소는 "물류창고 A"이고 메모는 비어 있습니다.
- 직접 하기: 등록 화면에 장소와 메모를 적고 사진 한 장을 고릅니다. 서버 창에서 서버를 끈 뒤 "사건 등록"을 누릅니다. 확인한 뒤 서버를 다시 켜고 Chrome을 새로고침합니다.
- 확인: 화면에 "오류: 로컬 서버에 연결하지 못했습니다."로 시작하는 글이 보이고, 적은 장소와 메모가 그대로 남아 있습니다. 단추 잠그기는 너무 빨리 지나가므로 AI 답에 넣었다고 나오는지 봅니다.
