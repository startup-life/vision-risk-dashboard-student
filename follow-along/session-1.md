# 1회차: 준비와 화면 틀, 확인 기준 목록

- 시작 상태: 빈 폴더에 만든 내 저장소에서 시작합니다. 코드는 하나도 없습니다. 1-2에서 AI가 수업 저장소의 `milestone-0` 브랜치에서 강사가 준 자료(`materials` 폴더), 프로젝트 규칙(`AGENTS.md`), 1회차 보충 문서(`docs/guide` 폴더)를 가져옵니다.
- 끝나면 되는 것: `npm.cmd start`로 서버를 켜면 브라우저에 화면 틀(머리말, 홈, 확인 기준 화면)이 보이고, 확인 기준 화면에 기준 9개가 표로 나옵니다. 만든 코드는 내 저장소에 커밋해 둡니다.
- 준비물: 인터넷이 되는 Windows 10·11 PC, 수업에 쓸 Google 계정 1개, 강사에게 초대받은 GitHub 계정(초대 메일의 수락까지 해 둡니다). Node.js와 Git은 1-1에서 AI가 설치합니다.

## 먼저 알아 둘 말

- **AI**: 프롬프트를 붙여 넣는 AI 도구입니다. 이 파일에서는 그냥 "AI"라고 부릅니다.
- **서버**: 앱 뒤에서 일하는 프로그램입니다. 서버를 켜 두면 Chrome에서 http://127.0.0.1:8765 주소로 앱을 엽니다.
- **터미널**: 명령을 치는 검은 창입니다. 이 수업에서는 시작 메뉴에서 여는 PowerShell 창을 씁니다.
- **서버 창**: 서버를 켜 두는 PowerShell 창입니다. 1-4에서 하나 정하고, 수업 내내 서버는 이 창에서만 켜고 끕니다. 다른 명령은 서버 창이 아닌 터미널에서 칩니다.
- **프로젝트 폴더**: `C:\vision-ai\vision-risk-dashboard`입니다. "시작 전에"에서 빈 폴더로 만들고, AI 도구에서 이 폴더를 열어 두고 작업합니다.
- **수업 저장소**: 강사가 GitHub에 둔 비공개 저장소입니다. 지침, 보충 문서, 강사 자료와 회차별 완료 코드가 들어 있고, 초대받은 GitHub 계정으로만 받을 수 있습니다. 이 프로젝트에서는 `class`라는 이름으로 부릅니다.
- **지침**: AI가 일하는 방식을 적은 `AGENTS.md` 파일입니다. 1-2에서 AI가 수업 저장소에서 가져와 이 지침을 따르게 합니다.
- **보충 문서**: 주소, 화면 문구, 거절 규칙처럼 세부 조건을 적은 문서입니다. `docs/guide` 폴더에 있습니다. 프롬프트는 무엇을 위해 어디에 어떤 기능을 더할지만 말하고, 세부 조건은 AI가 이 문서와 회차 완료 브랜치(1회차는 수업 저장소의 `milestone-1`)의 코드를 찾아 따릅니다. 사람은 읽지 않아도 따라 할 수 있습니다.

## 시작 전에 (직접 합니다)

1. AI 도구: 강사가 안내한 AI 도구를 설치하고 로그인합니다. Chrome도 있어야 합니다.
2. 프로젝트 폴더 만들기: 탐색기에서 `C:\vision-ai\vision-risk-dashboard` 폴더를 만듭니다. 바탕 화면, 문서 폴더, 한글이 든 경로는 쓰지 않습니다.
3. AI 도구로 폴더 열기: AI 도구에서 이 폴더를 엽니다. 폴더를 신뢰할지 물으면 신뢰하고, AI가 명령을 실행하기 전에 내 승인을 받게 합니다(도구마다 메뉴가 다릅니다). 그다음 새 대화를 시작합니다.

## 진행 방법

- 프롬프트 상자 하나를 통째로 복사해 AI에게 붙여 넣습니다. 앞 번호가 끝난 뒤에 다음 번호를 보냅니다.
- AI가 "이미 되어 있습니다"라고 답하면 그 번호의 "확인"만 해 보고 다음 번호로 넘어갑니다. 앞 번호에서 먼저 만들어졌을 수 있습니다.
- AI가 파일을 만들거나 명령을 실행해도 되는지 물으면 승인합니다. 서버를 켜겠다고 하면 거절합니다. 1-1의 프로그램 설치 말고, `Set-ExecutionPolicy`, `npm audit fix`처럼 컴퓨터 설정이나 프로그램 버전을 바꾸는 명령은 승인하지 말고 강사에게 알립니다.
- "직접 하기"는 AI에게 보내지 않고 내가 직접 합니다.
- 키, Google 웹앱 주소, 노트북 ID 같은 비밀 값은 설정 파일(`config/local-connection.json`)에만 둡니다. 화면 공유, 메신저, 문서에 옮기지 않습니다. 설정 파일은 Git에 올라가지 않습니다.
- 서버를 켠 뒤로는 번호가 끝날 때마다 서버 창에서 Ctrl+C로 끄고(물으면 `Y`) `npm.cmd start`로 다시 켠 다음, 브라우저를 새로고침(F5)하고 "확인"을 봅니다.
- "확인"과 다르게 나오면 화면의 글이나 서버 창의 빨간 줄을 그대로 복사해 "이렇게 나와요. 고쳐 주세요."와 함께 AI에게 붙여 넣습니다.
- 답이 이상해지면 새 대화를 열고 1-2의 프롬프트를 다시 보낸 뒤, 하던 번호부터 이어 갑니다.
- 화면 색과 배치는 예시와 달라도 됩니다. "확인"에 적힌 글과 동작만 같으면 됩니다.

## 1-1. 작업 준비

```text
이 폴더에서 웹앱을 만들 준비를 하기 위해, 이 PC에 Node.js(22.9 이상, 없으면 24 LTS)와 Git이 있는지 확인하고 없으면 설치해 주세요.
그다음 이 폴더를 내 git 저장소로 만들어 주세요. 끝나면 Node.js와 Git의 버전만 한 줄로 알려 주세요.
```
- 확인: AI 답에 `v24.`처럼 22.9 이상인 Node.js 버전과 Git 버전이 나옵니다.
- 직접 하기: AI가 프로그램을 새로 설치했으면 AI 도구를 닫았다가 다시 열고, 같은 폴더에서 새 대화를 시작합니다.

## 1-2. 지침 세팅

```text
수업 자료를 이 프로젝트로 가져오기 위해, 수업 저장소 https://github.com/startup-life/vision-risk-dashboard-student 를 이 프로젝트에 class라는 이름의 원격 저장소로 더해 받아 오고, class/milestone-0의 AGENTS.md, docs/guide, materials를 이 프로젝트로 가져와 주세요(브랜치는 옮기지 않습니다).
그다음 AGENTS.md를 작업 지침으로 삼아 주세요. 프롬프트에 없는 상세 구현(주소, 화면 문구, 파일 이름, 거절 규칙)은 docs/guide의 회차 문서와 그 회차 완료 브랜치 코드(class/milestone-1)에서 확인합니다.
지금은 AGENTS.md와 docs/guide/session-1.md를 읽기만 하고, 읽은 파일 이름만 한 줄로 알려 주세요.
```
- 직접 하기: 수업 저장소를 처음 받을 때 GitHub 로그인 창이 뜨면 강사에게 초대받은 GitHub 계정으로 로그인합니다.
- 확인: 탐색기의 프로젝트 폴더에 `AGENTS.md`, `docs`, `materials`가 생기고, AI 답에 `AGENTS.md`와 `session-1.md`가 나옵니다. 새 대화를 열 때마다 이 프롬프트를 먼저 보냅니다.

## 1-13. 내 설정 파일 만들기 (직접 하기)

프롬프트는 없습니다. 이 파일은 뒤 회차에서 키와 연결 정보를 넣을 때 그대로 씁니다.
- 직접 하기: 탐색기 보기 메뉴에서 "파일 확장명"을 켭니다. 그래야 이름을 바꿀 때 `.json`이 두 번 붙지 않습니다.
- 직접 하기: 탐색기에서 `config` 폴더의 `local-connection.example.json`을 같은 폴더에 복사하고, 복사본 이름을 `local-connection.json`으로 바꿉니다.
- 직접 하기: `local-connection.json`을 메모장으로 열어 내용을 `{ "TEST_KEY": "abc" }`로 바꿔 저장하고 서버를 다시 켭니다.
- 확인: 서버 창에 `TEST_KEY` 이름만 든 설정 경고가 나오고 `abc`는 나오지 않습니다.
- 직접 하기: 내용을 `{}`로 되돌려 저장하고 서버를 다시 켭니다.
- 확인: 경고 없이 서버가 켜집니다.

## 1-14. 내 코드 남겨 두기 (직접 하기)

프롬프트는 없습니다.
- 직접 하기: 서버를 끄고 터미널에서 아래를 한 줄씩 칩니다. 앞의 두 줄은 처음 한 번만 치고, 따옴표 안에 내 이름과 메일 주소를 넣습니다. 이 두 줄은 이 프로젝트에만 적용됩니다.

```powershell
git config user.name "내 이름"
git config user.email "내 메일 주소"
git add -A
git commit -m "1회차 화면 틀과 확인 기준"
```

- 확인: `git status`를 치면 "nothing to commit"이 나옵니다. `config/local-connection.json`은 커밋에 들어가지 않습니다.
