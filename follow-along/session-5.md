# 5회차: 사진 판독(Gemini)과 Google 시트 저장

- 시작 상태: 4회차를 끝낸 프로젝트 폴더(`C:\vision-ai\vision-risk-dashboard-student`)에서 이어 합니다. 4회차를 다 끝내지 못했으면 README의 "완료 브랜치로 옮기기"대로 `milestone-4`로 옮겨 시작합니다.
- 끝나면 되는 것: 사건 상세가 네 단계(1 사진, 2 AI 사진 설명 (Gemini), 3 관련 기준 확인 (NotebookLM), 4 내 판단 남기기)가 되고, 2번 구역에서 판독을 요청하면 Gemini가 쓴 사진 설명이 나옵니다. 관련 기준 확인은 이 설명이 있어야 할 수 있습니다. 사건 기록은 내 Google 시트와 Drive 비공개 폴더에 저장됩니다.
- 준비물: 개인 Google 계정 하나, OnePort API 키(`sk-`로 시작, 받는 방법은 강사 안내를 따릅니다), 4회차까지 쓴 설정 파일(`config/local-connection.json`)과 사진 저장소 폴더, 켜 둔 서버 창.

## 먼저 알아 둘 말

- **Gemini**: 사진을 보고 관찰한 내용을 글로 써 주는 Google의 AI입니다. 이 앱에서는 "AI 사진 설명"(AI 초안)을 씁니다.
- **OnePort**: 여러 AI를 한 곳에서 부를 수 있게 이어 주는 서비스입니다. 이 앱은 OnePort 키로 OnePort에 사진을 보내고, OnePort가 Gemini에 판독을 맡깁니다.
- **Google 시트·Drive**: 내 Google 계정의 표 문서와 파일 보관함입니다. 이 회차가 끝나면 사건 기록은 시트에, 사진은 Drive 비공개 폴더에 저장됩니다.
- **Google 쪽 코드(GAS)**: Google에서 돌아가는 코드(Apps Script)입니다. 내 컴퓨터의 서버가 이 코드에 시트 저장과 Gemini 판독을 맡깁니다. 내 컴퓨터에서는 실행해 볼 수 없어서 5-22에서 Google에 올린 뒤에 동작합니다.
- **웹앱 주소**: Google 쪽 코드를 부르는 주소입니다. 주소를 아는 사람은 누구나 내 시트 기록을 읽고 쓸 수 있으니 비밀 값으로 다룹니다.
- **스위치**: 설정 파일에서 연결 방식을 고르는 값입니다. `live`는 실제 연결, `mock`은 연습용 결과, `off`는 끄기입니다. 이번 회차에는 저장소, Gemini, NotebookLM 스위치 세 개를 씁니다.
- **연습 조합**: 스위치 세 개를 모두 `mock`으로 둔 상태입니다. Google 계정 없이 화면 흐름을 만들 때 씁니다.

## 시작 전에 (프롬프트 없이 직접 합니다)

1. 보충 문서 받기: 시작 메뉴에서 PowerShell 창을 새로 열고 아래 세 줄을 한 줄씩 칩니다. 세 줄을 꼭 함께 칩니다. 5회차의 자세한 내용을 적은 문서가 `docs/guide` 폴더에 들어오고 내 코드는 바뀌지 않습니다. 탐색기에서 `docs\guide` 폴더를 열어 `session-5.md`가 보이면 됩니다. 이 문서는 회차 끝 커밋 때 함께 저장됩니다. 4회차를 못 끝내서 `milestone-4`로 옮겼으면 문서가 이미 있으니 건너뜁니다.

```powershell
cd C:\vision-ai\vision-risk-dashboard-student
git fetch origin
git checkout origin/milestone-4 -- docs/guide
```

2. 서버 켜고 지난 회차 확인: 서버 창(1번의 PowerShell 창을 그대로 써도 됩니다)에서 `npm.cmd start`를 치고 Chrome에서 http://127.0.0.1:8765 를 엽니다. 사건 상세에서 "관련 기준 찾기"를 누르면 결과가 나오는지 봅니다.
3. Google 계정 준비: 개인 Google 계정 하나를 준비하고 Chrome에서 로그인해 둡니다. 4회차 NotebookLM에 쓴 계정이어도 됩니다. 학교·회사 계정은 웹앱을 "모든 사용자"로 여는 설정이 막힐 수 있습니다.

## 진행 방법

- 프롬프트 상자 하나를 통째로 복사해 AI에게 붙여 넣습니다. 앞 번호가 끝난 뒤에 다음 번호를 보냅니다.
- AI가 파일을 만들거나 명령을 실행해도 되는지 물으면 승인합니다. 서버를 켜겠다고 하면 거절합니다. `Set-ExecutionPolicy`, `npm audit fix`처럼 컴퓨터 설정이나 프로그램 버전을 바꾸는 명령은 승인하지 말고 강사에게 알립니다. `npm.cmd run gas:`로 시작하는 명령은 그 번호의 프롬프트에 적힌 명령일 때만 승인합니다.
- "직접 하기"는 AI에게 보내지 않고 내가 직접 합니다.
- 번호가 끝날 때마다 서버 창에서 Ctrl+C로 끄고(물으면 `Y`) `npm.cmd start`로 다시 켠 다음, 브라우저를 새로고침(F5)하고 "확인"을 봅니다.
- "확인"에 "Ctrl+F로 찾으면"이 있으면, 탐색기에서 그 파일을 메모장으로 열고 Ctrl+F를 눌러 그 글자를 칩니다. 찾은 글자가 선택되어 보이면 됩니다. 파일은 저장하지 않고 닫습니다.
- "확인"과 다르게 나오면 화면의 글이나 서버 창의 빨간 줄을 그대로 복사해 "이렇게 나와요. 고쳐 주세요."와 함께 AI에게 붙여 넣습니다.
- AI가 "이미 되어 있습니다"라고 답하면 그 번호의 "확인"만 해 보고 다음 번호로 넘어갑니다.
- 이번 회차는 길어서 아래 표의 부분이 바뀔 때(5-11, 5-20) 새 대화를 여는 것이 좋습니다. 새 대화를 열거나 답이 이상해지면 5-1의 프롬프트를 다시 보낸 뒤, 하던 번호부터 이어 갑니다.
- 확인에 "판독하지 않은 사건"이 필요한데 남은 사건이 없으면, 사진 1장으로 새 사건을 등록해 씁니다.
- 화면 색과 배치는 예시와 달라도 됩니다. "확인"에 적힌 글과 동작만 같으면 됩니다.

| 번호 | 하는 일 |
|---|---|
| 5-1 | 지침 세팅 |
| 5-2 ~ 5-10 | 연습용 사진 설명으로 화면 흐름 만들기 |
| 5-11 ~ 5-19 | Google 쪽 코드와 올리는 명령 만들기(아직 올리지 않음) |
| 5-20 ~ 5-29 | Google에 올려 실제로 연결하고 내 코드 남기기 |

Google 계정 준비가 안 됐으면 5-19까지 하고 5-29(내 코드 남겨 두기)를 한 뒤 "5회차 끝 확인"으로 갑니다.
