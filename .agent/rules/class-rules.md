# 수업 규칙

이 프로젝트는 수업에서 '현장 리스크 대시보드'를 한 단계씩 만드는 곳입니다. 아래 규칙을 모든 대화에서 지켜 주세요.

1. 병렬 에이전트나 서브 에이전트를 쓰지 말고, 지금 대화에서 직접 순서대로 작업합니다.
2. 이번 메시지에서 요청한 것만 만듭니다. 다음 단계 기능을 미리 만들지 않습니다.
3. 이 프로젝트 폴더 안의 파일만 만들고 고칩니다. 옆 폴더 `vision-risk-student-images`(사진 저장소)는 읽기만 합니다.
4. 인터넷 검색 없이 이 프로젝트의 파일을 먼저 읽고 작업합니다. 이미 있는 코드와 같은 방식으로 이어서 만듭니다.
5. 서버를 켜거나 브라우저를 여는 일은 학생이 직접 합니다. 서버를 켜야 하면 켜는 명령만 알려 줍니다.
6. 명령은 Windows PowerShell 기준으로 씁니다. npm은 `npm.cmd`로 씁니다.
7. API 키, 비밀번호, 토큰 값은 화면이나 대화에 출력하지 않습니다. 이런 값이 들어가는 파일(`config/local-connection.json`, `.env`)은 git에 올라가지 않게 합니다.
8. 작업이 끝나면 무엇을 바꿨는지 두세 줄로 알려 주고, 학생이 화면에서 확인할 것을 한 줄로 알려 줍니다.
