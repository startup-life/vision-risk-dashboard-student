# 지급 자료

따라하기 프롬프트에서 쓰는 원문 자료다. 앱 로직이 아니라 프롬프트로 만들 수 없는 원문 데이터와 그림이다. 따라 만드는 코드는 프롬프트가 시키는 대로 이 폴더의 파일을 읽거나 복사해 쓴다. 이 저장소의 완성된 브랜치 코드는 `courses/` 아래에 같은 내용의 사본을 두고 그것을 쓴다.

| 파일 | 내용 | 쓰는 회차 |
| --- | --- | --- |
| `standards.json` | 택배 발송·산업안전 확인 기준 목록 | 1회차부터 |
| `factory-logo.png` | 화면 머리글의 물류창고 로고 | 1회차 |
| `factory-criteria-v1.txt` | 검사 기준 원문. NotebookLM 노트북에 소스로 올린다 | 4회차 |
| `gemini-prompt.txt` | GAS가 Gemini에 사진과 함께 보내는 판독 지시문. 5회차에 GAS 코드 안으로 옮긴다 | 5회차 |
