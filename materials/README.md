# 지급 자료

따라하기 프롬프트에서 쓰는 원문 자료다. 앱 코드가 아니라 따라하기용 원문이며, 앱은 이 폴더를 읽지 않는다.

| 파일 | 내용 | 쓰는 회차 |
| --- | --- | --- |
| `standards.json` | 택배 발송·산업안전 확인 기준 목록 | 1회차부터 |
| `factory-logo.png` | 화면 머리글의 물류창고 로고 | 1회차 |
| `factory-criteria-v1.txt` | 검사 기준 원문. NotebookLM 노트북에 소스로 올린다 | 4회차 |
| `gemini-prompt.txt` | GAS가 Gemini에 사진과 함께 보내는 판독 지시문 | 5회차 |
