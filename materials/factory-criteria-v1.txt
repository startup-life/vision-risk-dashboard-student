물류창고 택배 발송·산업안전 확인 기준
기준 버전: 2026-10-02-v2
이 사이트의 가상 물류창고에 적용하는 운영 기준입니다. 실제 사업장의 규정이나 택배사의 접수 기준을 대신하지 않습니다. 사진만으로 주문 일치·구매자 주소·수량·배송 완료를 확정하지 않습니다.

C-01 머리 보호구
창고 A 작업 구역에서는 안전모를 착용합니다. 착용 의무 구역에서 안전모가 보이지 않으면 위험 여부를 검토합니다. 머리가 가려져 착용 상태를 확인할 수 없으면 판단을 보류합니다.
사진에 없는 위치와 작업 상황은 추가로 확인합니다.

C-02 제한구역 진입
지정 경계 안으로 대상이 들어오면 위험 여부를 검토합니다. 경계나 대상 위치를 확인할 수 없으면 판단을 보류합니다.
해당 구역의 제한 대상인지 확인되지 않으면 추가 확인이 필요합니다. 경계선의 색상이나 설비 종류만으로 제한구역을 단정하지 않습니다.

C-03 통로 적치
지정 통로 안에 장애물이 있으면 위험 여부를 검토합니다. 통로와 적치구역을 구분할 수 없으면 판단을 보류합니다.
정상 적치구역의 물건을 통로 장애물로 판단하지 않습니다.

C-04 바닥 고임
액체 고임의 경계와 주변 맥락을 확인해 미끄럼 위험 여부를 검토합니다. 반사와 액체를 구분할 수 없으면 판단을 보류합니다.
반사만으로 액체 고임을 단정하지 않습니다.

C-05 택배 포장 손상
발송 전 상자가 찢어져 내용물이 노출되거나 눌림으로 포장 보호 기능이 의심되면 발송을 보류하고 포장 상태를 확인합니다. 사진에서 손상 부위나 보호 상태를 확인할 수 없으면 판단을 보류합니다.
모서리의 작은 눌림만으로 발송 불가를 확정하지 않습니다. 내부 완충재와 상품 손상은 추가 확인합니다. 사진에 보이지 않는 상태를 정상으로 추정하지 않습니다.

C-06 택배 포장·상품 오염
발송 전 포장이나 상품 표면에 이물질, 젖은 흔적 또는 번진 얼룩이 보이면 발송을 보류하고 오염 여부와 상품 상태를 확인합니다. 그림자나 반사와 오염을 구분할 수 없으면 판단을 보류합니다.
얼룩만으로 누액 원인이나 내용물 오염을 확정하지 않습니다. 확인 후 재포장·상품 교체 여부를 사람이 기록합니다.

C-07 상품 라벨 확인
라벨이 필요한 상품은 발송 전 상품 라벨의 부착 상태를 확인합니다. 필요한 라벨이 없으면 발송을 보류하고 확인합니다. 부착 면이 가려져 있거나 라벨 필요 여부가 확인되지 않으면 판단을 보류합니다.
상품 라벨은 구매자 주소가 적힌 배송 라벨과 다릅니다. 상품 식별과 주문 일치는 실제 주문 자료를 따로 대조합니다.

C-08 병 상품 마개 확인
마개가 필요한 병 상품은 발송 전 마개의 존재와 입구가 닫혀 있는지 확인합니다. 마개가 없거나 입구가 열려 있으면 발송을 보류하고 확인합니다. 입구가 가려져 상태를 확인할 수 없으면 판단을 보류합니다.
마개가 보인다고 밀봉·누수 방지 성능까지 확인된 것은 아닙니다. 상품별 밀봉 상태와 운송 포장은 추가 확인합니다.

C-09 배송 라벨·주문 대조
택배 인계 전 배송 라벨과 실제 주문 자료를 대조해 수취인, 배송 주소, 상품과 수량이 맞는지 확인합니다. 라벨 누락이나 불일치가 있으면 발송을 보류합니다. 라벨을 읽을 수 없거나 주문 자료가 없으면 판단을 보류합니다.
사진 분류 모델은 주문 조회나 주소 검증을 하지 않습니다. 사진만으로 구매자에게 올바르게 발송됐거나 배송이 완료됐다고 기록하지 않습니다. 개인정보가 있는 라벨은 필요한 범위에서만 확인합니다.

사용자 판단
위험 확인: 적용 기준과 관찰 근거가 확인되어 리스크를 확인한 경우.
기준 충족: 선택한 기준을 충족한 것으로 확인한 경우. 택배 발송 승인이나 현장 전체의 안전 확인을 뜻하지 않습니다.
판단 보류: 관찰 근거나 적용 기준이 부족해 결정할 수 없는 경우.
해당 없음: 해당 기준이 적용되지 않는 대상·구역인 경우. 기준을 충족하는 정상 상태와 구분합니다.

모델 예측, Gemini 설명, NotebookLM 답변, 사용자 최종 판단은 서로 다른 기록입니다. 조치 완료 기록은 택배 발송·배송 완료를 뜻하지 않습니다.
